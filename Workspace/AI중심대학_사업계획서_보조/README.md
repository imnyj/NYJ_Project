# AI중심대학 사업계획서 보조 프로젝트

## 개요
이 디렉토리는 'AI중심대학 사업계획서 작성 및 보조' 작업을 위한 메인 작업 공간입니다.

## 파일 구성 안내
사용자께서 추가하실 사업계획서 관련 자료(문서, 데이터, 참고자료 등)를 이 디렉토리에 업로드하거나 추가해 주시면 됩니다.

- **원문 자료 및 참고 문헌**: 추가 예정
- **계획서 초안**: 추가 예정
- **기타 백업/로그**: `backup/` 및 관련 로깅 디렉토리에 자동 관리 예정

내용이 추가되는 대로 `multi-agent-manager` 스킬 하네스를 가동하여 서브 에이전트(예: 데이터 분석, 초안 작성, 교정 담당 등)에게 태스크를 분배하고 체계적으로 보조 작업을 진행하겠습니다.
