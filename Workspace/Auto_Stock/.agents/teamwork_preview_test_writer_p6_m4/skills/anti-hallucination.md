# Anti-Hallucination Skill
- Path Verification: Before reporting, explicitly double-check the absolute path.
- Strict Tone Formatting: Eliminate AI-like exaggerated words. Use dry, factual, objective tone.
- Evidence-Based Reporting: Physically read the output logs or CSV files using view_file or tools.
- 절대 경로 재확인 및 물리적 파일 존재 확인.
