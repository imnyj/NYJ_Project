### 2.2. 계산 엔진 모듈 (`etc/scripts/calc_engine.py`)

구현된 핵심 함수 및 기능:
1. `load_financial_params(json_path=None)`: `financial_params.json` 파일을 읽어 스키마를 검증하고 Dict 반환.
2. `calculate_r1_costs(price, is_first_home=True, params=None)`:
   - float 연산의 IEEE 754 부동소수점 오차 방지를 위해 모든 원 단위 금액 연산 시 `round()` 정수 변환 적용.
   - 3개 가격 시나리오별 R1 산출 결과:
     - **3.5억 원 시나리오**: 취득세류 165만 + 중개수수료 154만 + 법무사 50만 + 인지세 15만 + 채권할인 514,500 + 이사비 150만 + 수리청소비 200만 = **총 7,854,500 원** (필요 초기 자금 **357,854,500 원**)
     - **3.75억 원 시나리오**: 취득세류 192.5만 + 중개수수료 165만 + 법무사 52만 + 인지세 15만 + 채권할인 603,750 + 이사비 150만 + 수리청소비 200만 = **총 8,348,750 원** (필요 초기 자금 **383,348,750 원**)
     - **4.0억 원 시나리오**: 취득세류 220만 + 중개수수료 176만 + 법무사 55만 + 인지세 15만 + 채권할인 64.4만 + 이사비 150만 + 수리청소비 200만 = **총 8,804,000 원** (필요 초기 자금 **408,804,000 원**)
3. `calculate_r2_loans(price, cash_reserve=230000000, params=None)`:
   - 보유 현금 2.3억 원 차감 후 순 대출 필요액: **3.5억 시 1.2억 원 (LTV 34.29%)**, **3.75억 시 1.45억 원 (LTV 38.67%)**, **4.0억 시 1.7억 원 (LTV 42.50%)**
   - 차주부담 대출 인지세: **75,000 원 고정** (1억 초과 대출 시 15만 원의 50%)
   - 근저당 설정비: 은행 100% 부담, 차주 잡비 **20,000 원**
   - 연 보증료(HF): 1.2억 대출 시 연 **60,000 원** (0.05%)
   - 30년 원리금균등(CPM) 월 상환액:
     - 1.2억 디딤돌(3.15%): **515,684 원/월** vs 시중은행(4.25%): **590,328 원/월**
     - 1.45억 디딤돌(3.15%): **623,118 원/월** vs 시중은행(4.25%): **713,313 원/월**
     - 1.7억 디딤돌(3.15%): **730,553 원/월** vs 시중은행(4.25%): **836,298 원/월**
4. `run_all_scenarios(json_path=None)`: 3.5억/3.75억/4.0억 원 전체 시나리오 통합 실행 함수.
5. CLI 인터페이스:
   - `--all`: 전체 시나리오 실행
   - `--price <price>`: 특정 가격 계산
