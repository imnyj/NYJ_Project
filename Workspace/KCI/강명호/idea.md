* 주제: V2I 환경에서 최적 운송 기반 고속 Rectified Flow 체류 시간 예측 기법 (Optimal Transport-based Fast Rectified Flow Dwell Time Prediction Scheme in V2I Environments)
* 저자: 강명호, 남영주 (교신저자: 남영주)

### 1. 배경 및 문제점 (Motivation)
- **다봉성 체류 시간 분포의 예측 한계:** 도심 교차로에서 차량의 체류 시간은 정차 없이 통과하는 경우(약 10초)와 적색 신호에 대기하는 경우(약 40초 이상)로 나뉘는 GMM(Gaussian Mixture Model) 형태의 다봉성(Multimodal) 분포를 띰.
- **기존 회귀 모델의 평균 회귀 현상:** LSTM, GRU 등 기존의 결정론적 시계열 회귀 모델은 평균 제곱 오차(MSE)를 최소화하려는 특성 때문에 예측치가 두 봉우리의 중간값(약 25초)으로 수렴하는 '평균 회귀 문제'가 발생하여 프리캐싱 오작동 유발.
- **기존 생성 모델의 추론 지연:** DDPM 등 확산 모델은 정확도는 높으나 비선형적 확률 경로를 역추적하기 위해 수백 번의 디노이징 적분이 필요하므로, 연산 자원이 부족한 엣지(RSU) 환경에서 실시간 추론이 불가함 (수백 ms ~ 수 초 지연).
- **시뮬레이션 환경의 위치 추적 결함:** 도심 교차로 시뮬레이션 시 내부 연결 차선의 식별자 문제로 위치 파싱 오류가 발생하여, 일시적인 차량 이탈(이중 진입) 현상으로 오인되는 노이즈 존재.

### 2. 제안 기법 (Proposed Scheme)
- **최적 운송(Optimal Transport) 기반 Rectified Flow 적용:**
  - 가우시안 노이즈 분포와 실제 차량 체류 시간 데이터 분포 사이를 최단 거리인 '직선 확률 경로'로 매핑하는 Rectified Flow 기술 적용.
  - 직선 궤적을 학습함으로써 복잡한 역방향 근사 없이 고유 기하 정보를 직접 매칭.
- **오일러 기하 적분 기반 실시간 고속 추론:**
  - 궤적이 직선화되어 있어 단 10회 내외의 1차 오일러 적분(Euler Integration)만으로 3ms 이하의 초고속 실시간 예측 달성.
- **절대 좌표 기반 위치 오류 보정:**
  - TraCI API의 절대 좌표 조회 기능을 활용하여 교차로 내부 궤적 단절 오류를 복원하고, 데이터의 무결성을 확보.
- **차분 공간 변환 및 속도 네트워크(Velocity Network):**
  - 시간의 비가역성을 보존하기 위해 예측 대상을 차분 변환하고, Softplus 활성화 함수를 통해 시간의 순차적 모순을 원천 차단.

### 3. 시뮬레이션 환경 (Environment)
- 5km x 5km 맨해튼 그리드 기반 복합 교차로망 (43~60초 감응식 신호 제어).
- 총 9개의 RSU 배치 (기본 반경 800m, 도심 차폐 반영 300~500m 실 수신 반경).
- 통신 표준: IEEE 802.11p WAVE, 6Mbps 통신 대역폭.
- 채널 환경: 레일리 페이딩(Rayleigh Fading) 및 빌딩 회절 손실이 적용되어 통신 불확실성 극한 모사.

### 4. 핵심 결과 (Results)
- 체류 시간 예측 정확도: 평균 절대 오차(MAE) 2.1초 미만 달성 (기존 회귀 모델 대비 83% 이상 오차 개선).
- 실시간 처리 지연: 엣지 프로세서 환경 기준 추론 지연시간 3ms 이하 달성 (기존 확산 모델 대비 기하급수적 단축).
- 통신 성능 지표: 프리캐싱 적중률 85.5%, 스트리밍 세션 완료율 90.8% 확보.

### 5. 키워드 (Keywords)
