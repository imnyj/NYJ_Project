# bot: 친구용 디스코드 링크 프롬프트

친구의 Windows PC에서 Claude Code(CLI)가 스스로 디스코드 연동 스킬 `discord-link` 를 구현하고 설치하도록 하는 프롬프트 모음입니다.
코드는 전달하지 않고 프롬프트만 전달합니다(2026-09-11 결정).

## 파일

| 경로 | 내용 |
|---|---|
| `prompts/01_install_prompt.md` | 설치 프롬프트. `----- 프롬프트 시작 -----` 부터 `----- 프롬프트 끝 -----` 까지를 친구의 Claude Code 에 붙여 넣습니다 |
| `prompts/02_usage_prompts.md` | 설치 뒤에 쓰는 짧은 프롬프트와 디스코드 명령 안내 |
| `etc/temp/plan.md` | 작업 계획과 확인된 사실 |
| `etc/logs/` | 검증 기록 |

## 설치 프롬프트가 구현하게 하는 기능

1. 백그라운드 수신: 세션마다 Monitor 도구로 리스너를 띄워 디스코드 메시지를 세션 알림으로 받습니다. 훅은 보고만 하고 기다리지 않으므로 터미널 입력이 막히지 않습니다.
2. 설정 파일: `%USERPROFILE%\.discord-link\credentials.ini` 의 `token`, `channel_id` 두 줄만 채우면 됩니다. 설치 과정에서 Claude 가 경로와 여는 방법을 알려 줍니다.
3. 스킬 등록: `/discord-link [세션이름]` 한 번으로 이후 어느 세션이든 채널에 붙습니다.
4. 세션 구분: 세션 이름(스킬 인자, `claude -n`, `/rename` 순)으로 전용 스레드를 만들고, 채널 본문에서는 `@세션이름` 으로 받는 세션을 지정합니다.
   같은 이름이 겹치면 `-2` 를 붙이고, 터미널 세션 제목도 디스코드 이름과 같게 맞추며, `/clear` 뒤에는 연결을 새 세션으로 인계합니다.
5. 기타: `doctor` 점검, `status`, `unlink`, `rename`, `send`, 디스코드 제어어(`!stop`, `!mute`, `!status`, `!sessions`), 지시를 보낼 수 있는
   사용자 제한(`allowed_user_ids`), Monitor 를 쓸 수 없는 환경의 대체 수신 방식, 오프라인 테스트 31종, 문제 해결 안내.
6. 호출 방식: 디스코드에서 `@` 자동완성으로 봇 이름(`<@봇ID>`)이나 봇 이름의 역할(`<@&역할ID>`) 어느 쪽을 골라도 호출됩니다. 이 워크스테이션에서 두 형식을
   알아보지 못해 호출에 반응하지 않던 결함을 고친 경험을 명세에 담았습니다.
7. 팀 소통: `teams.conf` 에 팀을 정의하고 `team send` 로 세션끼리 메시지를 주고받습니다. 리스너가 팀 정의를 매 주기 다시 읽고, 연달아 10번 주고받으면 멈춥니다.
8. 코드 갱신 반영: 스크립트가 바뀌면 각 세션의 리스너가 알아채고 새 코드로 다시 띄우도록 Claude 에게 알립니다.

## 검증 상태

- 초안(438줄)은 새 서브에이전트가 프롬프트만 보고 가짜 홈 폴더에서 구현했고, 오프라인 테스트 18개가 통과했습니다(메인 세션이 다시 실행해 확인).
- 사실 검증과 시험 구현, 재검토에서 나온 지적을 반영해 두 차례 개정했습니다. 내역은 `etc/logs/verification.md` 에 있습니다.
- 2차 개정판을 다시 처음부터 구현해 보는 시험은 아직 하지 않았습니다. Windows 실기 시험도 이 워크스테이션(Linux)에서는 할 수 없습니다.

## 친구에게 필요한 준비물

- 최신 Claude Code CLI (Monitor 도구와 훅의 `args` 형식을 쓰므로 최신 버전을 권장합니다)
- Python 3.9 이상 (python.org 설치본 권장)
- Git for Windows (권장. 없으면 Claude Code 가 PowerShell 로 명령을 실행합니다)
- 디스코드 봇 하나와 봇 전용 비공개 채널 (만드는 방법은 설치 프롬프트 부록 A에 있습니다)

## 전달 방법

1. `prompts/01_install_prompt.md` 파일을 친구에게 보냅니다.
2. 친구는 홈 폴더에서 `claude` 를 실행하고 파일의 프롬프트 부분을 붙여 넣습니다.
3. Claude 가 설정 파일 위치를 알려 주면 친구가 토큰과 채널 ID 를 직접 적습니다. 토큰은 대화창에 붙여 넣지 않습니다.
4. 설치가 끝나면 `prompts/02_usage_prompts.md` 를 참고해 사용합니다.
