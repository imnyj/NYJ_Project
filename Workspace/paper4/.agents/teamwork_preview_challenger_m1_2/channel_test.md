## 1. 802.11p 무선 채널 모델 & 물리 수학 검증 (Nakagami-m & Path Loss)

### 1.1 수식 및 물리 모델
- **경로 손실 (Log-distance Path Loss)**:
  $$PL(d) = PL_0 + 10 \alpha \log_{10}(d / d_0)$$
  - $d_0 = 1.0\text{ m}$, $f_c = 5.9\text{ GHz}$, $\alpha = 2.0$, $PL_0 = 47.858\text{ dB}$
- **열 잡음 (Thermal Noise)**:
  $$N_{\text{thermal}} = -174 + 10 \log_{10}(10\text{ MHz}) + 10\text{ dB (Noise Figure)} = -94\text{ dBm}$$
- **수신 SNR 및 Nakagami-$m$ ($m=3$) 수신 확률**:
  $$\text{SNR}_{\text{lin}} = 10^{(P_{rx} - N_{\text{thermal}})/10}, \quad \text{SNR}_{\text{thresh}} = 5\text{ dB} = 3.162$$
  $$x = \frac{m}{\text{SNR}_{\text{lin}} / \text{SNR}_{\text{thresh}}} = \frac{3 \cdot \text{SNR}_{\text{thresh}}}{\text{SNR}_{\text{lin}}}$$
  $$P_{rx}(d) = e^{-x} \left(1 + x + \frac{x^2}{2}\right)$$
- **CBR 충돌 감쇄 계수 (Collision Attenuation Factor)**:
  $$f_{\text{col}}(CBR) = \max(0.1, 1.0 - 0.8 \times CBR)$$
- **최종 도달 성공 확률**:
  $$P_{\text{success}}(d, CBR) = P_{rx}(d) \times f_{\text{col}}(CBR)$$

### 1.2 수학적 / 전산적 무결성 실측 결과
1. **스칼라 vs 벡터화 연산 일치도**:

   - **Max Absolute Error**: $2.39 \times 10^{-15}$ (수치적 완벽 일치).
